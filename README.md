## Sobre o projeto

O **MODISH** é um protótipo de alta fidelidade de uma plataforma de e-commerce de moda, desenvolvido como projeto acadêmico para a disciplina de Interface e Jornada de Usuário, na Universidade Cidade de São Paulo (UNICID).

Inspirado na plataforma SHEIN, o projeto surgiu com o objetivo de propor melhorias na experiência do usuário, acessibilidade, organização visual e navegação durante a jornada de compra.

## Objetivo

Desenvolver uma interface de compras online que proporcione uma experiência mais intuitiva, prática e agradável, aplicando conceitos de UX Design e UI Design.

## Funcionalidades e telas

- Tela inicial com produtos em destaque.
- Navegação por categorias.
- Visualização de detalhes dos produtos.
- Carrinho de compras.
- Seleção de formas de pagamento.
- Confirmação do pedido.

## Design e experiência do usuário

Durante o desenvolvimento, foram aplicados conceitos e princípios de design, incluindo:

- Heurísticas de Nielsen.
- Lei de Fitts.
- Arquitetura da informação.
- Design Mobile First.
- Princípios de acessibilidade WCAG.
- Framework CRAP (Contraste, Repetição, Alinhamento e Proximidade).
- Jornada do usuário e personas.
